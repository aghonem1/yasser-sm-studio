# yasser-sm-studio

Private toolkit for the Yasser SM "One Word" reels. Start with RUNBOOK.md.

- remotion/ — animation project (reference episode: src/episodes/Ep03_Taaruf.tsx)
- scripts/ — narration timeline (split.py) and audio mix (audio.py)
- quran/verse.py — two-source verified verse excerpts
- tools/ — setup, audio relay client, speech-recognition check
- assets/ — CC0 sound effects (wyzowl/sfx-kit) and CC0 music (alvana-audio, HoliznaCC0)
- episodes/ — backlog and log
