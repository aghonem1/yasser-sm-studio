# Marketing skills (vendored)

Source: https://github.com/coreyhaines31/marketingskills, commit 8fd2fcade2fd6629026e9dfe6d133b55b36968b9 (23 Nov 2026), MIT licence (LICENSE-marketingskills.txt). Installed 25 Nov 2026 at Ahmed's request.

What is here: every skill's SKILL.md, references and templates. Left out on purpose: the repo's scripts, CLI tools and evals (nothing here runs code). To update: clone the source, copy `skills/*/` text files over this folder, change the commit above.

Every skill reads `.agents/product-marketing.md` first. That file's "Non-negotiable content rules", `RUNBOOK.md` and `research/learnings.md` override anything a skill suggests. The skills were written for software products; take the craft (clarity, hooks, structure, testing discipline) and drop anything that pressures, exaggerates or needs facts we do not have.

## Which skill for which job

|---|---|
| Daily carousel, reel hooks, captions | `social` (+ references/carousel-frameworks.md, references/short-form-video.md, references/platforms.md), `copywriting`, `copy-editing`, `marketing-psychology` (sparingly) |
| Reel and teaser video craft | `video`, `social` |
| Analytics audit, choosing the next test | `analytics`, `ab-testing`, `social` |
| Free live sessions (webinars) | `events`, `launch`, `emails`, `lead-magnets`, `co-marketing`, `community-marketing`, `marketing-plan` |
| Paid tests | `ads`, `ad-creative`, `attribution` |
| Weekly email, welcome and reminder flows | `emails`, `copywriting` |
| Website: book pages, sign-up, search | `cro`, `signup`, `popups`, `seo-audit`, `ai-seo`, `schema`, `site-architecture`, `content-strategy` |
